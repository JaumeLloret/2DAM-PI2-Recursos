# Acceso al legado AulaFlow 1.0

PI1 necesita examinar y ejecutar la versión **v1.0.0** del proyecto de referencia. El docente facilita el repositorio o un paquete autorizado por AULES, junto con el acceso necesario al historial y a la documentación del laboratorio.

1. Obtén ese acceso por el canal del curso. Esta biblioteca contiene la guía y las plantillas, pero no redistribuye el código del backend.
2. Comprueba el tag `v1.0.0` y el commit `c727814aa6deed46c37141ff3f98585136b49593` conforme al [procedimiento de PI1](PI1/Unidad/03_AUDITORIA_LEGADO_PI1.md).
3. Si recibes una URL Git, utiliza tu autenticación ya configurada. Sustituye el marcador del comando por esa URL; no introduzcas tokens en capturas, documentos o comandos compartidos.
4. Si recibes un paquete, conserva su versión y procedencia y sigue sus instrucciones de arranque. Pide los extractos históricos autorizados necesarios para el recorrido de PI1 si no están incluidos.
5. Si no puedes abrirlo, registra `PENDIENTE_ACCESO` con el recurso que falta y consulta al docente. Leer una guía no sustituye la ejecución requerida por G0.

El README y runbook del tag explican el arranque. Las PR y documentos históricos mencionados en las guías se consultan dentro del acceso facilitado. Los materiales públicos de contexto, teoría, práctica y plantillas siguen disponibles mientras se resuelve el acceso.
