# Recorrido documental del ejemplo

## Requisitos

Un lector de texto o editor capaz de abrir Markdown y JSON. No se necesita servidor, cuenta externa ni instalación de AulaFlow para este ensayo documental.

## Pasos y comprobación

| Paso | Acción exacta desde la carpeta ejemplo | Resultado esperado |
|---|---|---|
| 1 | Abre ENTREGA.md. | Identificador PI6-TRAIN-ENTREGA-R1 y ocho archivos descritos. |
| 2 | Abre estado_PI5.json y busca P3. | P3 no ejecutado y aceptación global no confirmada. |
| 3 | Abre tarjetas.json. | Dos entradas con id DEMO-01 y DEMO-02. |
| 4 | Abre INCIDENCIAS.md y busca I-P3. | Siguiente ensayo y condición de cierre explícitos. |
| 5 | Vuelve al índice y localiza REVISION.md. | Dificultad original, corrección y límite del ejemplo. |

Si falta un archivo, comprueba la carpeta y comunica archivo, versión, esperado y obtenido. No inventes el resultado.

Para repetir el recorrido sin modificar datos, cierra los archivos y vuelve a abrirlos. Si los editaste, conserva tu copia con otra revisión y descomprime una copia intacta del paquete. No se realizan operaciones sobre datos reales.

Lo observable es coherencia documental. No se ha probado login, permisos ni una aplicación real.
