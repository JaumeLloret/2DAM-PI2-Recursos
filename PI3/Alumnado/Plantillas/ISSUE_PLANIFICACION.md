# Plantilla de issue de planificación

Copia el contenido en una issue autorizada o tabla manual. Este archivo no crea issues ni solicita permisos por ti. Para TRAIN usa título `TRAIN-… · resultado`. Para AulaFlow conserva ID contractual auténtico; mientras no exista catálogo no crees tareas nominales.

- Naturaleza/versión: TRAIN o REAL / TBD.
- ID contractual y fuente: PENDIENTE_CATALOGO.
- Actividad local / hito: TBD.
- Criterio contractual preservado: TBD.
- Entrada necesaria y dependencia FS/SS con causa: TBD.
- Salida observable y evidencia prevista: TBD.
- Persona responsable / revisión / tiempo: TBD.
- Recurso, logística y permiso previo: TBD.
- Riesgo/trigger/contingencia: referencia P09 TBD.
- Preparación: POR_ACLARAR.
- Bloqueo, responsable y revisión: TBD.
- PR/evidencia futura: pendiente; no crear enlace ficticio.
- Aceptación: decisión docente pendiente; solo ACEPTADA valida AT.
- Cambio: baseline anterior / motivo / CR si modifica alcance / nueva vigencia, TBD.
