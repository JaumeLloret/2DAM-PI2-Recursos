# PI3 · Planificación, arquitectura global y preparación de ejecución

Edición 2026–27 · **15 h = 900 min**. Un paquete integrado P01–P12 que conecta fases, actividades, arquitectura, recursos, capacidad, riesgos y evidencias.

Empieza por el [índice del alumnado](Alumnado/00_INDICE_ALUMNADO_PI3.md) y sigue la [guía de trabajo](Unidad/01_GUIA_ALUMNADO_PI3.md). La ruta incluye lectura, práctica, talleres y equivalencias; no suma una entrega por cada archivo.

Usa los casos marcados TRAIN para practicar. El catálogo auténtico se entrega por el canal autorizado; las plantillas REAL permanecen vacías hasta cotejar la selección del equipo. [Cómo trabajar con el catálogo](../CATALOGO_Y_CONTRATO.md).
