# Plantilla REAL pendiente

No contiene tareas, IDs, tarifas ni AT. No copies el JSON TRAIN. Usa esta plantilla solo en un espacio autorizado con fuentes auténticas. El cotejo del catálogo se controla en #34. `null` significa desconocido, no cero. Hasta contar con libro, contrato y evidencia, mantiene PENDIENTE_CATALOGO y colecciones contractuales vacías.

Puedes registrar observaciones reales no contractuales de preparación, con fecha real, fuente y límite, sin convertirlas en historia de sprints o aceptación. Los identificadores contractuales posteriores se trasladan literalmente desde el anexo cotejado, no se generan. No publiques datos privados, firmas ni secretos. El validador comprueba coherencia formal; nunca concede puertas o aceptación.
