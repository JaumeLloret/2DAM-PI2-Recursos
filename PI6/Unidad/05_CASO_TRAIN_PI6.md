# ReservaLab Traspaso · caso TRAIN completo

Ficción didáctica con archivos documentales reales para inspeccionar. Recibe V09 de PI5: candidato C2, ocho comprobaciones funcionales del modelo conformes, integración con doble y usuarios C2 pendientes, ninguna aceptación suministrada. No contiene aplicación ejecutable, datos de empresa, AT ni historia auténtica de AulaFlow. Los archivos permiten comprobar de verdad rutas/huellas de documentación sintética; no probar un despliegue.

## Entrada del paquete

Abre [uso](../Alumnado/Train/Paquete_entrada/docs/uso.md), [operación](../Alumnado/Train/Paquete_entrada/docs/operacion.md), [notas](../Alumnado/Train/Paquete_entrada/docs/release_notes.md), [pendientes](../Alumnado/Train/Paquete_entrada/docs/known_issues.md), [trazabilidad](../Alumnado/Train/Paquete_entrada/docs/trazabilidad.md) y [manifiesto](../Alumnado/Train/Paquete_entrada/manifest.json). El manifiesto tiene dos defectos deliberados: referencia de archivo y huella de contenido. No se distribuye como ejemplo correcto. Las frases señaladas en operación/notas también requieren revisión de coherencia. No edites el original: trabaja en una copia y conserva el antes/después.

| Requisito de contexto TRAIN | Estado recibido de PI5 |
|---|---|
| TRAIN-01 consulta | Cotejo funcional completo del modelo C2, con límite de entorno |
| TRAIN-02 reserva integrada | Modelo C2 conforme; servicio compartido pendiente |
| TRAIN-03 cancelación/historial y claridad | Modelo C2 conforme; usuarios C2 pendientes |
| TRAIN-04 importación válida/rechazo | Cotejo funcional completo del modelo C2 |

No cambies estos estados por corregir un manual. Los roles TRAIN-INTEGRACION y TRAIN-REV son personajes del ejercicio, no destinatarios a los que debas contactar. TRAIN-RESP es rol de decisión, sin aprobación favorable suministrada. G6/G7 se revisan, sin satisfacción real concedida; G2–G5 mantienen la activación disponible en el escenario, no se activan por inventario.

## Producto

F01–F10 y copia corregida del paquete documental, con manifiesto de nuevo corte. Cada cambio distingue defecto de integridad, incoherencia de documentación y pendiente de producto. Una solución correcta conserva integración, usuarios, entorno y defensa real pendientes. No genera ACEPTADA, firma, release real ni AT.

El caso está completo para trabajar las 720 min: lectura, inspección, mapa, transferencia, riesgos, retrospectiva, contribución, ensayo y corrección. La observación individual REAL se mantiene pendiente hasta organización docente, con sustitución de tiempo. No se inventa calendario de retorno.
